# Northflare

Build a custom app for your Shopify store with your own AI, and have
Northflare host it. This repository is Northflare's plugin for Claude Code
and Codex: it adds the Northflare connector, which shows your apps and
drafts the plan for a new one, and the instructions your agent follows.

Claude Code:

```
claude plugin install northflare --marketplace tobymarsden/northflare-plugin
```

Codex:

```
codex plugin marketplace add tobymarsden/northflare-plugin
codex plugin add northflare@northflare
```

Then start a new session, sign in to Northflare when asked, and tell your
agent what you'd like your app to do.
